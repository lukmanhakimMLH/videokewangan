# Klien Unit Trust

App satu fail (`index.html`) untuk agent unit trust rekod klien, pelaburan, redemption dan prestasi.

**Cara guna:** buka `index.html` dalam browser (phone atau laptop). Tak perlu internet atau install apa-apa.

1. Tab **Dana & Harga** → tambah dana + harga NAV.
2. Tab **Klien** → tambah klien → `+ Pelaburan` / `− Redeem` / `+ Agihan`.
3. Tekan nama klien → app minta update harga pasaran untuk dana yang klien pegang.
4. **Backup** selalu (data simpan dalam browser peranti tu sahaja).

Kiraan: kos purata (sales charge masuk dalam kos), untung realis/belum realis, jumlah pulangan %, % unit diredeem, % modal dikeluarkan.
