# videokewangan

## Perancang Kewangan Bulanan (`app/`)

App web (PWA) untuk rancang kewangan setiap bulan — buka `app/index.html` di browser, atau host folder `app/` (GitHub Pages / Netlify) dan "Add to Home Screen" di telefon.

- **Pendapatan** – gaji bersih + bank mana duit masuk, pendapatan tambahan (ulang setiap bulan atau sekali).
- **Perbelanjaan** – rekod apa yang dibeli/dibayar ikut kategori, bil tetap bulanan, bajet ikut kategori.
- **Hutang** – pinjaman rumah/kereta/peribadi/PTPTN, kad kredit, PayLater (SPayLater, Atome, Grab, EPP bank…) dengan kiraan ansuran automatik dan tanda "sudah bayar".
- **Utama** – baki boleh guna, DSR, carta pecahan duit keluar, aliran tunai 6 bulan.
- Beberapa profil (Suami/Isteri), mod gelap, backup/pulih JSON. Data disimpan dalam peranti sahaja.
